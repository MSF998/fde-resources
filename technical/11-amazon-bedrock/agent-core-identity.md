## Key Concepts
- OAuth - 2 Legged Auth
    - no user in middle
    - machine to machine
- OAuth - 3 Legged Auth
    - requires user to provide consent
    - flow
        - user redirection
        - user consent
        - code exchange: one time auth code
        - token request
        - resource access

- inboud auth
    - who is allowed to talk to my agent
- outbound auth
    - agent access to the resources
    - is the agent allowed to access to resource on behalf of the user
