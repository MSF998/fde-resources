## Key Concepts

- AI Agents
  - Are autonomous software entities powered by LLMs that process natural language requests
  - components of AI agents
    - Agentic Frameworks
    - Agentic Protocols
    - LLMs

- Agentic Protocols
  - communication standards and rules that define how different systems, agents and components interact with each other
  - Components of Agentic protocols
    - AG-UI: standardize how human instructions are handled and streaming UI updates
    - A2A : Agent to agent protocol facilitates agent communication for collabration. Like TCP IP
    - MCP: a protocol that standardizes tool calls and context handling with different models.
      - Components
        - tools
          - functions with a name, description, and JSON schema for arguments
        - resources
        - prompt templates
