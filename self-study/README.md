# Self-Study

Independent learning outside the FDE course — YouTube courses, playlists, books, docs, and anything else worth tracking as I go.

Each topic folder (`topic-name/`) contains:
- `notes.md` — log of what I actually learn, organized per unit/video/chapter (not just a completion checklist — that lives in [PROGRESS.md](../PROGRESS.md))
- `resources.md` — links to the source material and supplementary references
